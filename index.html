A production-ready SaaS backend, in Go.

Multi-tenant workspaces, auth, RBAC, background jobs, and observability — the boring stuff every B2B SaaS needs, already done and wired on free-tier services.

View on GitHub Quickstart

What’s included

Multi-tenancy done right

Shared Postgres with row-level security plus explicit tenant_id filters. Safe on PgBouncer via SET LOCAL per transaction.

Supabase Auth

JWT verification through JWKS; users lazy-upserted from claims on each request — no auth webhooks to operate.

Casbin RBAC

Role-based access with domains (owner / admin / member), policies stored in Postgres, per-org enforcer cache.

Background jobs

Asynq on Upstash Redis for email sends, invite expiry, and anything that shouldn’t block a request.

Idempotency & rate limits

Idempotency-Key support and per-IP/per-user rate limiting as standard middleware, backed by Redis.

Observable by default

OpenTelemetry traces across API, worker, and Postgres to Grafana Cloud; structured JSON logs with request/trace IDs.

Domain events

Watermill in-process events for fan-out side effects, with explicit durable-task boundaries where loss matters.

Sane errors

RFC 9457 problem+json responses; sentinel errors map to status codes in one place, not in every handler.

Free-tier hosting

Designed around Supabase, Upstash, Grafana Cloud, Resend, and GitHub Actions — $0 until you have real traffic.

Quickstart

# clone and configure
git clone https://github.com/ntxinh/go-saas.git && cd go-saas
cp .env.example .env   # Supabase URL/key, Upstash Redis, Resend key

# run migrations, then the API
go run ./cmd/seed      # optional: demo orgs + users
go run ./cmd/api
go run ./cmd/worker    # background jobs, separate process

Designed for agents & humans

Feature-sliced layout with a hard boundary rule — features import internal/shared and nothing else, enforced by go-arch-lint in CI. Flat manual wiring in one wire.go; no framework magic to decode at 3am.
